1. Executive Summary & Project Motivation

AI Care Box is an autonomous, software-only intelligent care companion developed in pure modern C++. It was conceived to address two urgent societal challenges within a unified, elegant object-oriented framework:

  • Elderly Healthcare & Loneliness Mitigation: Senior citizens often experience difficulties remembering complex daily prescription routines, staying properly hydrated, and seeking immediate emergency assistance when feeling unwell.
  • Busy Professional Productivity: High-performing knowledge workers need concise daily scheduling, focused task queues, and structured reminder management without intrusive clutter or privacy-invasive third-party cloud trackers.

2. Object-Oriented Programming (OOP) Pillars Applied

The entire codebase strictly demonstrates the core foundational pillars of Object-Oriented Software Engineering:

OOP Pillar Implementation Strategy Codebase Evidence & Manifestation
Encapsulation All class member variables are strictly declared private. State modifications are permitted solely through validated public setters, getters, and business methods. Reminder::isDone, DailyCheckIn::isOkay, FamilyContact::phone, ReminderManager::count are fully hidden from outside tampering.
Inheritance Hierarchical sub-typing with a common polymorphic base class. Concrete roles inherit identity properties and extend specialized domain state. class ElderlyUser : public User and class ProfessionalUser : public User inherit identity fields (name, age, language) while adding medicine/task queues.
Polymorphism Dynamic method dispatch through virtual member functions and virtual destructors. Derived classes supply specialized behavior invoked through base class pointers. virtual void showTasksOrMedicines() const; and virtual void showProfile() const; dynamically adapt in DailyBriefing depending on whether an elderly or professional user is logged in.
Abstraction Complex subsystems expose clean, human-readable interfaces while concealing algorithmic details, bounds checks, and pointer management. CareBox::run() presents an intuitive 8-option interactive menu, hiding lower-level buffer flushes, string tokenization, and dynamic memory reclamation.
Composition & Association Entities are composed together or linked via pointers to form collaborating subsystems with clear ownership boundaries. CareBox owns ReminderManager, FamilyContact, DailyCheckIn, DailyBriefing, and VoiceAssistant. DailyCheckIn holds a pointer association to FamilyContact.
